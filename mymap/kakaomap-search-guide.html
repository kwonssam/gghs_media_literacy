API 핵심 개념 요약

NASA 실습에서 배운 내용 중 카카오맵 실습에 꼭 필요한 개념만 빠르게 정리.

API란?

외부 서버의 데이터를 가져오는 통로.
규칙대로 요청하면 데이터가 배달 옴.
🛵 배달앱처럼 주방 몰라도 주문 가능

JSON이란?

API가 데이터를 보낼 때 쓰는 포장 형식.
key : value 쌍으로 구성.
📦 data.name, data.x, data.y 로 꺼냄

API 키란?

정식 사용자임을 증명하는 코드.
키 없으면 서버가 요청 거절.
🔑 개발자 사이트에서 무료 발급

NASA API vs 카카오맵 API — 방식이 다름!
NASA는 fetch()로 URL 호출 → JSON 수신 방식.
카카오맵은 SDK 스크립트 설치 → 지도 UI + 데이터 통째로 제공하는 방식.
지도 확대·축소·마커 같은 복잡한 UI는 JSON 텍스트만으론 구현 불가 → 카카오가 미리 만든 도구 상자(SDK)를 통째로 설치해서 사용.

🧭 이 프롬프트의 각 줄이 무엇이 되나요?
핵심 줄만 골랐어요. 줄마다 화면에 무엇이 생기는지, 받은 뒤 무엇을 확인할지 먼저 봐요.
프롬프트에 쓰는 것화면에 생기는 것내가 확인할 것
③왼쪽, 오른쪽 2분할왼쪽 검색창과 리스트, 오른쪽 지도화면이 둘로 나뉘었나?
③현재 위치를 중심으로내 위치에서 지도가 시작됨엉뚱한 곳에서 시작하지 않나?
③카카오 JavaScript 키카카오가 지도 사용을 허락함내 키가 들어갔나?
④index.html 하나로파일 하나에 붙여넣기만 하면 됨파일이 하나인가?
📋 STEP 1 프롬프트 — 선생님과 같이 입력해요
선생님이 왜 이렇게 쓰는지 생각하면서 따라 써봐요
① 페르소나 나는 고등학생이고 HTML/CSS/JS를 처음 배우고 있어. ② 맥락 카카오맵 API로 장소 검색 서비스를 새로 만들고 싶어. 카카오 JavaScript SDK를 사용해서 지도를 표시하는 거야. ③ 구체적 지시 아래 조건으로 만들어줘: - 화면을 왼쪽(검색창 + 결과 리스트)과 오른쪽(지도)으로 2분할 - 페이지가 열리면 위치 권한을 허용 받아서 현재 위치를 중심으로 지도에 표시 - 지도가 제대로 로드된 후에 실행되도록 해줘 (로딩 오류 방지) - 지도 확대 레벨은 5 - 카카오 JavaScript 키: [내 JavaScript 키] ④ 출력 형식 HTML, CSS, JS를 하나의 index.html 파일로 합쳐서 보여줘. 변수명은 영어로, 주석은 한국어로.

  "place_url": "http://place.map.kakao.com/..."  // 카카오맵 링크
}

핵심 코드 — AI가 이런 코드를 넣어줄 거예요 (검색어 탭은 keywordSearch, 코드 탭은 categorySearch를 써요)

var ps = new kakao.maps.services.Places();
var infowindow = new kakao.maps.InfoWindow({ zIndex: 1 });

ps.keywordSearch(keyword, function(data, status) {
  if (status === kakao.maps.services.Status.OK) {
    data.forEach(function(place) {
      // ① 마커 찍기
      var pos = new kakao.maps.LatLng(place.y, place.x);
      var marker = new kakao.maps.Marker({ map: map, position: pos });

      // ② 리스트에 이름 추가
      var item = document.createElement('div');
      item.textContent = place.place_name;
      document.getElementById('result-list').appendChild(item);

      // ③ 마커 클릭 시 팝업
      kakao.maps.event.addListener(marker, 'click', function() {
        infowindow.setContent('<div style="padding:8px"><b>' + place.place_name + '</b><br>' + place.road_address_name + '</div>');
        infowindow.open(map, marker);
      });
    });
  }
});

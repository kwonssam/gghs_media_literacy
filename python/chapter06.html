데이터를 지도 위에 — 지도 시각화

같은 folium, 같은 다섯 단계. 그런데 데이터가 바뀌면 해야 할 일이 달라집니다.
세 가지 데이터를 탭으로 바꿔 가며 그 차이를 직접 확인합니다.

📌 수업 유의사항

  • 코드를 외우지 않습니다. 복사해서 실행하고, 숫자와 단어를 바꿔 보는 것이 오늘의 공부입니다.
  • 지도가 한 번에 안 떠도 정상입니다. 오류 메시지를 그대로 읽는 연습부터 합니다.
  • 아래 탭 세 개는 순서대로 하는 것을 권합니다. A → B → C로 갈수록 데이터가 까다로워집니다.
  • C 탭(동물병원)은 카카오 API 키가 필요합니다. 키가 없으면 A·B만으로도 수업은 완결됩니다.

🎯 이 장에서 배우는 것

학습 목표
  • folium.Map()으로 원하는 곳이 중심인 지도를 띄울 수 있다
  • 마커를 찍고 popup·tooltip으로 정보를 달 수 있다
  • for문으로 CSV의 모든 위치에 마커를 찍을 수 있다
  • MarkerCluster로 많은 마커를 묶어 볼 수 있다
  • 데이터가 수천·수만 건일 때 CircleMarker·FastMarkerCluster로 가볍게 그릴 수 있다
  • 필터링으로 원하는 지역·종류만 뽑을 수 있다
  • 지오코딩(주소→좌표)과 역지오코딩(좌표→주소)을 구분하고 쓸 수 있다
  • 데이터마다 해야 할 준비 작업이 다르다는 것을 설명할 수 있다

import requests

def 주소로_좌표찾기(주소):
    url = 'https://dapi.kakao.com/v2/local/search/address.json'
    headers = {'Authorization': f'KakaoAK {KAKAO_API_KEY}'}
    결과 = requests.get(url, headers=headers, params={'query': 주소}).json()

    if 결과['documents']:

        return float(결과['documents'][0]['y']), float(결과['documents'][0]['x'])
    return None, None

⚙️ 전복 실습의 모델은
어떻게 답을 냈을까?

지난 시간 Linear Regression과 kNN으로 전복의 순살 무게를 맞혔습니다. 오늘은 두 모델이 안에서 어떻게 답을 냈는지 원리를 보고, Test and Score의 R²가 무엇을 잰 숫자인지, 그리고 Rank · Test and Score · Predictions가 각각 언제 쓰는 위젯인지 정리합니다.

🎯 이 장에서 배우는 것

  • 전복 데이터에서 독립변수 x와 종속변수 y를 구분하고, 알고리즘과 모델의 차이를 말할 수 있다
  • Linear Regression이 오차(MSE)가 가장 작은 직선을 찾는 원리를 설명할 수 있다
  • kNN이 가장 비슷한 데이터 K개의 평균으로 답하는 원리를 설명할 수 있다
  • Test and Score의 MAE · MSE · RMSE · R²를 읽고, R²의 뜻을 설명할 수 있다
  • Rank · Test and Score · Predictions의 쓰임을 구별할 수 있다

🧩 알고리즘과 모델은 다르다

「Linear Regression」은 모델일까, 모델을 만드는 방법일까?

알고리즘 — 규칙을 찾는 방법

데이터에서 규칙을 어떻게 찾을지 정해 둔 절차입니다. Linear Regression, kNN, Tree, Random Forest는 모두 알고리즘의 이름입니다. 오렌지3에서는 Learner라고 부릅니다.

모델 — 그 방법으로 찾아낸 규칙

알고리즘이 특정 데이터로 학습을 마치고 만들어 낸 결과입니다. 「전복 데이터로 학습한 Linear Regression 모델」처럼 데이터가 정해져야 생깁니다. 오렌지3에서는 Model이라고 부릅니다.

같은 알고리즘이라도 카페 데이터로 학습하면 카페 모델, 전복 데이터로 학습하면 전복 모델이 됩니다. 지난 시간에는 알고리즘 4개로 같은 전복 데이터에서 모델 4개를 만든 것입니다.

모델 안에 남는 것은 알고리즘마다 다르다

Linear Regression: 각 x에 곱할 숫자(계수)와 절편. 실습의 「기계가 만든 식 엿보기」에서 본 Coefficients가 바로 이것입니다.
kNN: 학습 데이터 전체. 미리 규칙을 정리해 두지 않고, 질문이 오면 그때 비슷한 데이터를 찾습니다.

위젯 연결의 열쇠

Linear Regression 위젯은 Learner(방법)와 Model(학습을 마친 결과)을 따로 내보냅니다. 어느 쪽을 어디에 연결하느냐가 Test and Score와 Predictions의 차이입니다. PART E에서 자세히 봅니다.

Linear Regression은 x와 y의 관계를 직선 하나로 나타내는 알고리즘입니다. 그 직선을 어떻게 찾는지 카페 데이터로 먼저 보고, 전복으로 넓힙니다.

📈 규칙을 직선으로: y = a × x + b

기계는 「판매량 = 온도 × 2」라는 규칙을 어떻게 찾아냈을까?

기울기 a

x가 1 늘 때 y가 평균적으로 얼마나 변하는지. 「온도가 1도 오르면 판매량이 몇 잔 늘어나나」입니다.

절편 b

직선 전체의 높이를 위아래로 맞추는 값입니다.

Linear Regression의 학습은 데이터를 가장 잘 설명하는 a와 b를 찾는 일입니다. 기계는 처음부터 정답 직선을 아는 것이 아니라, 아래 4단계를 반복하며 직선을 조금씩 고쳐 나갑니다.

STEP 1 데이터 표시

기록을 그래프 위에 점으로 찍고 전체 경향을 봅니다.

STEP 2 아무 직선 긋기

기울기와 절편을 아무렇게나 정해 직선을 하나 긋습니다.

STEP 3 오차 재기

각 점과 직선 사이의 세로 거리(오차)를 잽니다.

STEP 4 직선 고치기

오차가 줄어드는 쪽으로 직선을 조금 옮깁니다. 이 반복이 학습입니다.

📏 오차와 MSE

「잘 맞는 직선」은 무엇으로 판단할까?

오차실제 y − 직선이 예측한 y. 점과 직선 사이의 세로 거리입니다.
MSE (평균 제곱 오차)오차를 제곱해서 평균 낸 값. 작을수록 잘 맞는 직선입니다.
학습의 목표MSE가 가장 작아지는 a와 b 찾기
왜 오차를 그냥 더하지 않고 제곱할까?+5와 −5를 그냥 더하면 0이 되어 「오차가 없다」고 착각하게 됩니다. 제곱하면 모두 양수가 되고, 크게 빗나간 점일수록 더 크게 벌을 줍니다.

선형 회귀에서 학습이란? 데이터를 가장 잘 설명하는 직선을 찾는 것이고, 그 방법은 오차(MSE)가 줄어들도록 a와 b를 계속 고쳐 나가는 것입니다. 학습이 끝나면 그 직선(모델)으로 처음 보는 x의 y를 예측합니다.

➕ x가 여러 개라면: 다중 선형 회귀

전복 실습에서는 x가 4개였다. 그때 모델은 어떻게 생겼을까?

x가 하나면 직선 y = a × x + b이지만, x가 여러 개면 x마다 곱할 숫자(가중치, 오렌지3에서는 계수 coefficient)를 하나씩 찾습니다. 이것을 다중 선형 회귀라고 합니다.

전복 모델 (실험 ②)순살무게 = w₁ × 길이 + w₂ × 직경 + w₃ × 두께 + w₄ × 전체무게 + b

실습의 「기계가 만든 식 엿보기」에서 Coefficients를 Data Table로 꺼냈을 때 나온 숫자들이 w₁, w₂, …와 b입니다. 기계는 MSE가 가장 작아지도록 이 숫자들을 한꺼번에 찾습니다.

x를 많이 넣는다고 항상 좋아지지는 않는다y와 상관없는 x를 넣으면 데이터의 우연한 잡음까지 외워 버릴 수 있습니다(과적합). 그리고 실습의 실험 ①처럼, 실제로 쓸 상황에서 얻을 수 없는 x(껍질을 깐 뒤에야 잴 수 있는 무게)는 점수가 높아도 쓸 수 없습니다.

📍 비슷한 전복이면 순살 무게도 비슷하다

전복 실습에서 kNN은 새 전복의 순살 무게를 어떻게 정했을까?

kNN(K-최근접 이웃)은 새 전복의 x(길이·직경·두께·전체무게)와 가장 가까운 전복 K마리를 학습 데이터에서 찾아, 그 전복들의 y(순살 무게) 평균을 답으로 냅니다. 오렌지3 kNN 위젯의 기본값은 K = 5입니다.

1 재료 준비

x를 정해 데이터 한 건 한 건을 공간의 점으로 만든다.

2 거리 계산

새 데이터와 모든 학습 데이터 사이의 거리를 잰다.

3 이웃 탐색

거리가 가장 짧은 K개를 고른다.

4 결과 예측

회귀는 이웃 y의 평균, 분류는 이웃 y의 다수결.

🎮 이웃의 평균 vs 직선 하나

실험 ③에서 kNN이 Linear Regression을 이긴 이유는?

kNN 예측 (이웃 평균)
직선 예측

전복의 길이와 순살 무게 관계를 본떠 만든 점들입니다. 초록 점이 고른 이웃, 주황 선이 Linear Regression의 직선입니다.

Linear Regression: 직선 하나로 전체를 설명

길이가 2배가 되면 무게는 약 2×2×2 = 8배가 되기 때문에, 길이와 순살 무게는 휘어진 곡선 관계입니다. 직선은 이 곡선을 따라가지 못해서 아주 작거나 아주 큰 전복에서 크게 빗나갑니다.

kNN: 그 근처의 이웃만 본다

kNN은 관계의 모양을 미리 정하지 않습니다. 새 전복 근처의 이웃 평균을 내니, 곡선이 휘어 있어도 그 자리의 높이를 따라갑니다. 그래서 겉모양만 쓴 실험 ③에서 kNN이 이겼습니다.

그럼 실험 ②에서는 왜 Linear Regression이 이겼을까?실험 ②에는 전체무게가 x로 들어 있었습니다. 전체무게와 순살무게는 둘 다 무게라서 거의 곧게 함께 변합니다. 직선으로 잘 설명되는 관계에서는 Linear Regression이 강합니다.

🔧 K와 단위가 결과를 바꾼다

K가 너무 작으면

바로 옆의 이상한 전복 하나(측정 실수 등)에 답이 휘둘립니다. 위 시뮬레이터에서 K = 1로 바꿔 보세요.

K가 너무 크면

멀리 있는, 전혀 다른 크기의 전복까지 평균에 끼어들어 답이 뭉개집니다. K = 50으로 바꿔 보세요.

🔁 성적표 숫자는 이렇게 만들어진다: 교차 검증

Test and Score는 어떤 데이터로 시험을 봤을까?

지난 수업에서 「공부한 문제집으로 시험을 보면 안 된다」고 했습니다. 그런데 데이터를 학습용과 평가용으로 한 번만 나누면, 어느 전복이 평가용에 들어갔느냐에 따라 점수가 운 좋게 또는 운 나쁘게 나올 수 있습니다. 그래서 Test and Score는 교차 검증(Cross validation)을 씁니다.

  1. 전체 데이터를 똑같은 크기의 덩어리 5개로 나눕니다(5겹).
  2. 1번 덩어리를 평가용으로 숨기고, 나머지 4개로 알고리즘을 새로 학습시킨 뒤 1번 덩어리로 점수를 냅니다.
  3. 평가용 덩어리를 2번, 3번, 4번, 5번으로 바꿔 가며 다섯 번 반복합니다. 모든 전복이 한 번씩 평가용이 됩니다.
  4. 다섯 번의 결과를 모아 낸 점수가 Test and Score에 적힌 숫자입니다.
그래서 Test and Score에는 알고리즘(Learner)을 연결합니다. 이미 학습을 마친 모델 하나를 받는 게 아니라, 덩어리마다 새로 학습을 시켜야 하기 때문입니다. 성적표의 숫자는 모두 학습에 쓰지 않은 데이터로 낸 점수입니다.

📊 회귀 성적표의 네 지표

MAE, MSE, RMSE, R²는 각각 무엇을 잰 숫자일까?

지표계산단위좋은 쪽읽는 법
MAE
평균 절대 오차		|실제 y − 예측 y|의 평균y와 같음작을수록「평균적으로 이만큼 틀렸다」
MSE
평균 제곱 오차		(실제 y − 예측 y)²의 평균y의 제곱작을수록큰 실수에 벌을 크게 준 오차. PART B에서 직선을 찾을 때 줄인 바로 그 값
RMSE√MSEy와 같음작을수록MSE를 원래 단위로 되돌린 값. 전복 실습에서는 × 200을 해서 g으로 읽음
R²
결정계수		1 − (모델의 오차 제곱합 ÷ 평균으로 찍었을 때의 오차 제곱합)없음1에 가까울수록평균으로만 찍었을 때보다 오차를 몇 %나 줄였나 (아래에서 자세히)
RMSE를 실제 크기로 읽기전복 데이터의 무게는 원래 g을 200으로 나눈 값입니다. RMSE가 0.02라면 0.02 × 200 = 4, 즉 「순살 무게를 평균 4g쯤 빗나간다」로 읽습니다. 단위가 있는 지표는 이렇게 원래 단위로 바꿔 말해야 뜻이 분명해집니다.

🎯 R² 결정계수: 평균으로 찍는 것보다 얼마나 나은가

R² = 0.939는 「93.9% 맞혔다」는 뜻일까?

아닙니다. R²를 이해하려면 기준부터 알아야 합니다. 모델이 아무것도 배우지 않고 모든 전복을 평균 순살 무게로 찍는다고 해 봅시다. 이게 가장 쉬운 답입니다. R²는 모델이 이 「평균으로 찍기」보다 오차를 몇 %나 줄였는지를 나타냅니다.

R² = 1

모델의 오차가 0. 모든 점을 정확히 맞혔다.

R² = 0

평균으로 찍은 것과 오차가 같다. x에서 배운 것이 없다.

R² < 0

평균으로 찍은 것보다도 오차가 크다. 시뮬레이터에서 기울기를 반대로 돌려 보세요.

R² = 0.939 읽는 법 「모든 전복을 평균 무게로 찍었을 때 생기는 오차(제곱의 합) 중 93.9%를 모델이 줄였다」. 전복 실습에서 쓴 「x들이 순살 무게의 변화를 93.9% 설명한다」와 같은 말입니다. 전복마다 순살 무게가 들쭉날쭉한 정도 가운데, x로 설명해 낸 몫이 93.9%라는 뜻입니다.

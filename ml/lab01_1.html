🐚 껍질을 까지 않고
순살 무게를 맞힐 수 있을까?

전복 4,177마리의 데이터로 순살 무게를 예측하는 회귀 모델을 오렌지3에서 직접 만들어 봅니다. 모델을 만드는 데서 끝나지 않고, 데이터를 의심하고, 어떤 단서를 쓸지 실험하고, 내가 만든 전복으로 예측까지 해 봅니다.

🎯 이 실습에서 할 것

학습 목표
  • 오렌지3에서 feature와 target을 지정하고 회귀 모델을 만들 수 있다
  • Test and Score의 R², RMSE, MAE를 읽고 모델을 비교할 수 있다
  • 데이터에서 이상치를 찾아 처리하고 결과가 어떻게 바뀌는지 확인할 수 있다
  • 문제 상황에 맞는 특성(단서)을 골라야 하는 이유를 설명할 수 있다
  • 내가 만든 데이터로 모델의 예측을 확인할 수 있다
준비물: 오렌지3 · 전복 데이터 구글 시트 열기 (파일 → 다운로드 → 쉼표로 구분된 값(.csv))

01데이터 분석이 만드는 사회적 가치
데이터 분석은 우리 일상의 어떤 문제를 풀 수 있을까?

데이터 분석은 판매자·전문가만 알던 정보를 모두에게 공개하고(정보 비대칭 해소), 보이지 않던 낭비를 숫자로 드러내고, 소외된 사람들도 데이터 기반 서비스의 혜택을 받게 합니다. 아래 6가지 사례를 보세요.

#학습 유형분석 주제주요 단서 (X)맞힐 값 (Y)사회적 가치
1지도 · 회귀🐚 전복 순살 무게길이, 직경, 두께, 전체 무게순살 무게정보 비대칭 해소 · 공정 거래
2지도 · 분류🩺 당뇨병 여부혈당, BMI, 혈압, 나이, 가족력당뇨 여부 (0/1)예방 의료 · 의료 격차 해소

02오늘의 질문 — 껍질을 까지 않고 순살 무게를 알 수 있을까?
전복을 살 때 우리는 무엇을 알 수 있고, 무엇을 모를까?
🐚 상황
전복은 껍질을 포함한 전체 무게로 거래됩니다. 하지만 실제로 먹는 순살의 양은 껍질 두께 등에 따라 크게 달라서, 껍질을 까기 전까지는 진짜 가치를 알 수 없어요. 만약 겉모습만 보고 순살 무게를 예측할 수 있다면, 판매자만 알던 '순살 비율'을 소비자도 확인할 수 있고, 순살 기준으로 공정한 가격을 매길 수도 있겠죠.

순살무게먹을 수 있는 살의 무게 → 맞힐 값(target)—
⚠️ 숫자 단위 주의: 이 데이터의 숫자는 실제 값(mm, g)을 200으로 나눈 값이에요. 예를 들어 길이 0.455는 약 91mm, 순살무게 평균 0.36은 약 72g이에요. 그래서 결과를 해석할 때 "0.039g"처럼 읽으면 안 되고, 200을 곱해 실제 크기로 바꿔 생각해야 해요.
👀 표를 다시 보세요: 나이테는 껍질에 보이지만, 정확히 세려면 껍질을 잘라 염색한 뒤 현미경으로 봐야 해서 시간이 오래 걸려요. 오늘의 질문 "껍질을 까지 않고"에 쓸 수 있는 단서는 무엇일까요? PART C에서 직접 실험해요.

Q2①②에서는 Linear Regression이 1등인데, ③에서는 kNN과 Random Forest가 이겼어요. 왜일까요?
💡 생각한 뒤 눌러 보기
무게는 크기의 세제곱에 비례해서, 겉모양(길이·직경·두께)과 순살무게 사이는 곡선 관계예요. 직선만 그을 수 있는 Linear Regression은 곡선을 잘 따라가지 못하고, 이웃을 보는 kNN이나 나무 여러 그루가 나눠 맞히는 RF는 곡선에도 잘 맞춰요. 반면 ①②에는 순살무게와 거의 직선 관계인 전체무게가 들어 있어서 직선 모델이 유리했어요. 항상 1등인 모델은 없고, 데이터와 단서에 따라 달라져요.
💡 기계가 만든 식 엿보기 (선택)

Linear Regression은 2차시에서 배운 직선 식을 만드는 모델이에요. 기계가 실제로 어떤 식을 만들었는지 직접 볼 수 있어요.

  1. Select Columns에서 단서를 전체무게 하나만 남겨요.
  2. Select Columns → Linear Regression → Data Table을 연결해요.
  3. 표에 숫자 두 개가 나와요.
📷 오렌지3 화면 캡처 자리 — Data Table (Linear Regression 식의 숫자)
이름숫자2차시 식에서는
전체무게0.44a (기울기)
intercept0.00b (절편)

※ intercept는 화면에 −0.004처럼 0에 아주 가까운 작은 숫자로 보일 수 있어요. 0이라고 봐도 돼요.

그러니까 기계가 만든 식은 이거예요.

순살무게 = 0.44 × 전체무게 + 0

말로 하면 "순살은 전체무게의 약 44%"예요. 100g짜리 전복이면 순살은 약 44g이라고 예측하는 거죠.

단서를 4개로 늘리면 표에 숫자도 4개(+ intercept)가 나와요. 식이 길어질 뿐, 하는 일은 2차시 직선과 똑같아요.

💡 생각한 뒤 눌러 보기

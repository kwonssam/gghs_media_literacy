📢 머신러닝 기반
사회 문제 해결 탐구

데이터를 찾고, 머신러닝 모델을 기획해 오렌지3로 만들고, 내 말로 설명한다.

📌 평가 개요

  • 주제 데이터로 일상 · 사회 문제를 해결하는 머신러닝 모델
  • 데이터 공공데이터포털 · 통계청(KOSIS) · 빅카인즈 · 캐글 등의 실제 원본
  • 방식 수업 3차시 탐구 보고서 + 짝 설명

✅ 필수 포함 내용

항목쓸 것수업에서 배운 것예시 장면
(1) 문제 정의
  • 해결할 문제
  • 만들어 낼 사회적 가치
  • 한 줄 정의: 무엇을 넣으면 무엇을 알려 주는가
  • 규칙으로 못 푸는 문제 → 머신러닝 (수업 1)
(2) 데이터 설계
  • 출처(URL) · 행 수 · 열 수 · 범위
  • Feature / Target 구분
  • 열마다 수치형 · 범주형
  • 데이터에 없는 요인
  • 행 = 사례, 열 = 특성 (수업 2)
  • feature · target · meta · skip
  • 범주형(명목 · 순서) · 수치형(이산 · 연속)
  • 빅데이터 의심하기 (수업 2)
(3) 모델 선택
  • 지도 / 비지도
  • 회귀 / 분류 / 군집
  • 고른 모델과 이유
  • 다른 유형이 아닌 이유
  • Target 수치형 → 회귀
  • Target 범주형 → 분류
  • 정답 없음 → 군집
  • 배운 모델 → 위 모델 지도
(4) 학습 결과
  • Test and Score 캡처
  • 여러 모델 점수 비교
  • 지표를 한 문장으로 풀기
  • 회귀: R² · RMSE · MAE (수업 5)
  • 분류: CA와 기준점, Recall · Precision (수업 5)
  • 군집: 실루엣 계수로 k (수업 8)
(5) 테스트
  • 넣기 전 예상 → 실제 출력 → 차이의 까닭
  • 전형 · 경계 · 범위 밖 값 하나씩
  • Predictions 캡처
  • Predictions: 학습 마친 모델에 새 데이터 (수업 5)
  • 분류는 확률, 기준선은 사람이 정함 (수업 9)
(6) 한계와 윤리
  • (5)를 근거로 한 한계
  • 틀렸을 때 누가 피해를 보나
  • 개선 방안
  • 데이터에 없는 정보는 모델도 모름 (수업 10)
  • 두 종류의 틀림 (수업 9)
  • 비대표성 · 민감함 (수업 2)

🗣️ 짝 설명 · 3차시 끝 10분

  1. 2분 설명: 「내 모델은 무엇을 받아 어떻게 답을 내는가」
  2. 짝이 말로 질문 하나 → 답하기
  3. 역할 바꾸기
  4. 보고서에 짝 이름 · 받은 질문 · 나의 답 적기
배우지 않은 모델을 썼다면짝 설명에서 그 모델의 원리를 설명할 수 있어야 한다.

🎯 평가 기준

기획 및 데이터 설계 · (1)~(3)

  • 창의적 접근, 사회적 · 경제적 가치
  • 출처가 있는 실제 데이터
  • 논리적인 Feature(x) · Target(y)
  • Target 형태에 맞는 알고리즘과 이유

설명 가능성 · (4)~(6) · 짝 설명

  • 입력 → 원리 → 결과의 흐름을 쉽게 설명
  • 유형에 맞는 지표로 결과 해석
  • 근거를 든 한계(윤리 · 데이터 부족 등)
  • 짝의 질문에 논리적으로 답함
수준기획 및 데이터 설계설명 가능성
상
  • 문제 · 데이터 · 유형의 근거가 이어짐
  • 출처 · 범위 · 빠진 요인 제시
  • 다른 유형이 아닌 이유까지 설명
  • 지표를 단위 · 기준점으로 해석
  • 테스트 세 가지로 원리와 한계 제시
  • 짝 질문에 원리로 답함
중
  • 구체적인 문제 정의
  • 출처 있는 데이터로 Feature · Target 구분
  • Target 형태에 맞는 유형 선택
  • 지표 기록
  • 예상과 결과 비교
  • 근거 있는 한계 하나 이상
하
  • 주제 · 데이터 선정
  • Feature · Target 기재
  • 학습 결과 · 테스트 화면 첨부
  • 결과 기재

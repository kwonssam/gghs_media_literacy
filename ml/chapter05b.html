5 · Test and Score와 Predictions
수업 5 · 개념 · Test and Score와 Predictions · 🐚 전복 · 🚢 타이타닉

🧾 모델의 성적표,
무엇으로 채점하고 어떻게 읽을까?

전복 실습에서 Test and Score의 숫자를 봤습니다. 오늘은 ① 그 숫자가 어떤 데이터로 채점한 점수인지, Predictions와 무엇이 다른지 보고, ② 맞힐 값이 숫자인 회귀(전복)와 이름표인 분류(타이타닉)의 성적표를 나란히 놓고 숫자 하나하나를 읽습니다.

🎯 이 장에서 배우는 것

  • Test and Score는 정답이 있는 데이터를 학습용과 시험용으로 나눠, 시험용에 대한 모델의 예측을 정답과 비교해 채점한다는 것을 설명할 수 있다
  • Predictions는 정답(target)이 없는 새 데이터를 넣어 예측값만 받는 위젯이라는 것을 구별할 수 있다
  • 회귀 성적표의 R² · RMSE · MAE를 실제 단위(g)로 읽을 수 있다
  • 분류 성적표의 CA · Precision · Recall · F1 · AUC · MCC를 타이타닉 예로 읽을 수 있다
  • 맞힐 값이 숫자인지 이름표인지에 따라 성적표가 달라지는 까닭을 말할 수 있다

🗺️ 오늘의 흐름

채점과 예측 구분→회귀 성적표 · 전복→분류 성적표 · 타이타닉→한눈에 비교

회귀 지표는 수업 3(전복), 분류 지표는 수업 6(트리 · 타이타닉)부터 계속 씁니다. 분류 성적표를 깊게 다루는 것은 수업 8입니다.

둘 다 모델이 예측을 하는데, 무엇이 다를까?

🧾 Test and Score — 정답을 아는 데이터로 채점

넣는 것: 정답(target)이 적힌 데이터 + 알고리즘(Learner)

전복쓰임실제 순살모델 예측
1~4학습용알려 줌—
5시험용103.8g (가려 둠)115.2g

데이터를 학습에 쓰는 부분과 모델이 예측해 볼 부분으로 나눕니다. 학습용으로 모델을 만든 뒤, 시험용은 정답을 가린 채 예측시키고, 예측값과 가려 둔 진짜 정답을 비교해 점수를 냅니다.

받는 것 — 모델마다 점수 한 줄 (R², RMSE … / CA, AUC …)

🔮 Predictions — 정답이 없는 데이터를 예측

넣는 것: 정답(target)이 없는 새 데이터 + 학습을 마친 모델(Model)

내 전복실제 순살모델 예측
A (전체무게 180g)? 모름79g
B (전체무게 320g)? 모름141g

시장에서 껍질을 까기 전의 전복처럼 진짜 정답을 아직 모르는 데이터를 넣고 예측값을 받습니다. 비교할 정답이 없으니 점수는 나오지 않습니다.

받는 것 — 데이터 한 줄마다 예측값
Test and Score = 정답을 아는 데이터로 「잘 맞히는지」 채점하는 위젯(학습용과 시험용을 구분해 씁니다). Predictions = 정답을 모르는 데이터의 답을 실제로 물어보는 위젯. 그래서 점수를 보려면 Test and Score, 예측값을 보려면 Predictions입니다.

위 예측값은 전복 실습 실험 ②(껍질 까기 전 단서 4개)의 Linear Regression으로 계산한 값입니다. 내 전복 A·B의 예측은 전체무게만 보고 대략 0.44를 곱한 값입니다.

Test and Score는 어떤 데이터로 시험을 봤을까?

수업 1 「머신러닝 · 지도와 비지도」에서 「공부한 문제집으로 시험을 보면 안 된다」고 했습니다. 그런데 데이터를 학습용과 평가용으로 한 번만 나누면, 어느 전복이 평가용에 들어갔느냐에 따라 점수가 운 좋게 또는 운 나쁘게 나올 수 있습니다. 그래서 Test and Score는 교차 검증(Cross validation)을 씁니다.

  1. 전체 데이터를 똑같은 크기의 덩어리 5개로 나눕니다(5겹).
  2. 1번 덩어리를 평가용으로 숨기고, 나머지 4개로 알고리즘을 새로 학습시킨 뒤 1번 덩어리로 점수를 냅니다.
  3. 평가용 덩어리를 2번, 3번, 4번, 5번으로 바꿔 가며 다섯 번 반복합니다. 모든 전복이 한 번씩 평가용이 됩니다.
  4. 다섯 번의 결과를 모아 낸 점수가 Test and Score에 적힌 숫자입니다.
그래서 Test and Score에는 알고리즘(Learner)을 연결합니다. 이미 학습을 마친 모델 하나를 받는 게 아니라, 덩어리마다 새로 학습을 시켜야 하기 때문입니다. 성적표의 숫자는 모두 학습에 쓰지 않은 데이터로 낸 점수입니다.

MAE = 12.6g

오차의 크기만 평균: (37.7 + 6.2 + 0.4 + 9.1 + 11.4 + 11.0) ÷ 6. 「평균 12.6g쯤 틀렸다」

MSE ≈ 299 g²

오차를 제곱해서 평균. 단위가 g²이라 크기가 와닿지 않습니다.

RMSE = 17.3g

MSE에 √를 씌워 g으로 되돌린 값. 37.7g짜리 큰 실수를 더 무겁게 쳐서 MAE보다 큽니다.

RMSE가 MAE보다 훨씬 크면 「가끔 크게 틀리는」 모델입니다. 전복 1번(−37.7g)처럼 한두 마리를 크게 놓치면 RMSE가 확 커집니다.

🎯 R² 결정계수: 평균으로 찍는 것보다 얼마나 나은가

🧾 이 수업의 흐름① 채점과 예측 구분② 회귀 지표 · 전복③ 분류 지표 · 타이타닉④ 회귀 vs 분류⑤ 정리

R² = 0.939는 「93.9% 맞혔다」는 뜻일까?

아닙니다. R²를 이해하려면 기준부터 알아야 합니다. 모델이 아무것도 배우지 않고 모든 전복을 평균 순살 무게로 찍는다고 해 봅시다. 이게 가장 쉬운 답입니다. R²는 모델이 이 「평균으로 찍기」보다 오차를 몇 %나 줄였는지를 나타냅니다.

R² = 1

모델의 오차가 0. 모든 점을 정확히 맞혔다.

R² = 0

평균으로 찍은 것과 오차가 같다. x에서 배운 것이 없다.

R² < 0

평균으로 찍은 것보다도 오차가 크다. 시뮬레이터에서 기울기를 반대로 돌려 보세요.

R² = 0.939 읽는 법 「모든 전복을 평균 무게로 찍었을 때 생기는 오차(제곱의 합) 중 93.9%를 모델이 줄였다」. 전복 실습에서 쓴 「x들이 순살 무게의 변화를 93.9% 설명한다」와 같은 말입니다. 전복마다 순살 무게가 들쭉날쭉한 정도 가운데, x로 설명해 낸 몫이 93.9%라는 뜻입니다.

성적표에 있던 Tree와 Random Forest는 어떻게 답을 냈을까?

오늘은 Linear Regression과 kNN의 속을 열어 봤습니다. 실험 ②의 성적표에는 아직 설명하지 못한 숫자가 남아 있습니다. Tree 0.886, 네 모델 중 꼴찌입니다.

Linear Regression: 직선 하나

전체무게와 순살 무게가 거의 곧게 함께 늘어나니, 직선이 잘 따라갑니다. → 0.939

Tree: 질문으로 나눈 칸마다 평균

「전체무게가 186.5g보다 무거운가?」처럼 질문으로 전복을 나누고, 칸마다 평균으로 답합니다. 그래서 예측 그래프가 계단이 됩니다. → 0.886

다음 실습에서는 이 계단이 어떻게 만들어지는지 전복으로 직접 확인하고, 같은 트리가 이름표(타이타닉 생존/사망)를 맞힐 때는 무엇이 달라지는지 봅니다. 트리 여러 그루를 모은 랜덤 포레스트도 만나요. kNN이 이름표를 맞히는 방법(다수결)은 그다음 kNN 실습에서 펭귄으로 다룹니다.

🧭 정리 평가

✅ 스스로 점검

  • Test and Score와 Predictions가 받는 데이터(정답 있음 / 없음)와 내놓는 것(점수 / 예측값)을 구별할 수 있다
  • 교차 검증이 학습용과 시험용을 바꿔 가며 채점하는 방법임을 말할 수 있다
  • 전복 RMSE · MAE를 × 200 해서 실제 g으로 읽을 수 있다
  • R²를 「평균으로 찍을 때보다 줄인 오차의 비율」로 설명할 수 있다
  • 혼동 행렬의 네 칸으로 CA · Precision · Recall을 계산할 수 있다
  • 상황에 따라 Precision과 Recall 중 무엇을 볼지 고를 수 있다
